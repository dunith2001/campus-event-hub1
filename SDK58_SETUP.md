# SDK 58 setup

1. Open this folder in VS Code.
2. Run `npm install`.
3. Run `npx expo install --fix` to align dependencies with Expo SDK 58.
4. Run `npx expo-doctor` and resolve any issues.
5. Start Android Emulator, then `npx expo start -c` and press `a`.
6. Test all screens, state sharing, AppState, and local notifications.

This package is a migration starting point, not a verified working build.
